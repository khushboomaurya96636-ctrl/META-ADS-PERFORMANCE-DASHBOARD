# META ADS PERFORMANCE DASHBOARD

## 📌 PROJECT OVERVIEW
The Meta Ads Performance Dashboard is a data analytics and visualization project developed using Power BI. The dashboard helps analyze advertising campaign performance by transforming raw Meta Ads data into meaningful insights through interactive visualizations and KPI tracking.

This project enables users to monitor important advertising metrics such as impressions, clicks, conversions, engagement, and click-through rates (CTR), helping businesses make data-driven marketing decisions.

---

## 🎯 PROJECT OBJECTIVE
The main objective of this project is to:
- Analyze Meta Ads campaign performance
- Visualize marketing data effectively
- Track KPIs and engagement metrics
- Identify trends and audience behavior
- Support better decision-making using dashboards
